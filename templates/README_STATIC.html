Mazer — Static HTML/CSS/JS + Bootstrap

This package runs without Nunjucks, Laravel Mix, npm, or a build step.

  • Open index.html directly, or serve this folder using any simple local server.
  • All 59 compiled HTML pages are retained.
  • Bootstrap and vendor libraries are stored under assets/.
  • assets/css/responsive-enhancements.css adds mobile/tablet fixes.
  • assets/js/responsive-enhancements.js adds responsive table wrappers and mobile sidebar backdrop behavior.
